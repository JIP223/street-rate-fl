How we put a page together

  1. We read the company’s website. We only use that company’s own page for a named location, never a guess from a booking site.
  2. We copy what it shows. The ad price, and a later price only when the company prints one, like “Months 5–12 in-store rent.”
  3. We add the date and show the math. Fees and insurance only when the same page states them. If we can’t confirm it, we leave it out.
